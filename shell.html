Shell 스크립트 통합 학습노트

1번 줄 #!/bin/bash → chmod 700 → ./실행

스크립트는 1번 줄 #!/bin/bash부터 쓴다(첫 줄을 비우지 않음) — #를 빠뜨리면 1번 줄 오류. ./파일.sh는 x 권한이 있어야 실행되고 bash 파일.sh는 읽기(r)만 있어도 실행 → chmod 700을 먼저. 변수는 이름=값에 = 양옆 띄어쓰기 금지, 계산은 괄호 두 겹 $(( ))(한 겹 $( )는 명령 실행이라 오류).

if [ 조건 ]; then · -eq · && · || · read

조건문은 if [ 조건 ]; then → elif → else → fi로 닫고, [ ] 안은 값·연산자 사이를 전부 한 칸씩 띄움. 같다는 = 하나, 숫자 비교는 -eq·-ge, 실무는 (( )) 산술 조건에 &&(모두)·||(하나라도). 입력은 echo -n + read로 같은 줄에서 받고 $변수로 사용. 리눅스 명령도 조건이 됨 — if systemctl is-active --quiet "$dm"; then은 종료 코드 0이면 then.

for · while · until · 배열 · break · 함수 · case

반복은 for(값 목록·(( )))·while(증가를 본문 안)·until(종료 조건) — done이 빠지면 문법 오류, 증가식을 빼면 무한 루프. 배열은 번호 0부터 ${#d[@]} − 1까지, 순회는 for in, break로 강제 종료. case는 esac로 닫고 각 파트는 ;;, 함수는 괄호를 비우고 인자를 $1·$2로 받으며 호출은 선언 아래. 자동화는 today=$(date +%Y%m%d) → cp -a·rsync -avz → crontab 5필드(분 시 일 월 요일) 순서로 이어지고, 패키지 설치는 dnf install -y를 셸 한 파일에 모아 root로 실행.

순서할 일주의·이유

# [호스트 리눅스 · vi 명령 모드 · blue2]

# [호스트 리눅스 · vi 입력 모드 · blue2 · test.sh 파일 안]
# 1번 줄부터 두 줄 입력 (첫 줄을 비우지 않음)
#!/bin/bash
echo "hi"
# [호스트 리눅스 · vi 명령 모드 · blue2]

# [호스트 리눅스 · blue2 · 프롬프트 $]

chmod 700 test.sh       # 소유자에게 rwx 부여 → 파일명이 녹색으로 바뀜
./test.sh               # 실행 → hi 출력

chmod +x와 chmod 700 — 실행 권한을 누구에게 줄지

명령결과주의·이유
chmod +x file1.shuser·group·other 모두에게 x(실행) 부여세 주체 전부에 실행 권한 — 자주 나오는 함정

# [호스트 리눅스 · blue2 · 프롬프트 $ · /home/blue2]

chmod 700 file1.sh   # 정석 — 소유자만 실행, 게스트 실행 차단
./file1.sh           # 이후 실행도 같은 방식

# [호스트 리눅스 · vi 입력 모드 · blue2 · date1.sh 파일 안]
#!/bin/bash
today=$(date +%Y-%m-%d)    # 명령 결과를 변수에 — 괄호 $( ) 필수
time=$(date +%H:%M:%S)
echo $time                 # 변수는 echo로 찍어야 출력
# [호스트 리눅스 · blue2 · 프롬프트 $]
chmod 700 date1.sh
./date1.sh                 # 변수에 담은 시:분:초가 출력되면 정상

산술 계산 — $(( ))

코드결과이유

num=$userid+$userid255+100 문자로 출력변수 값은 들어가지만 계산은 안 됨

num=$(userid+userid2) (괄호 한 겹)./test2.sh: 7: userid: … 오류$( )는 명령 실행이라 userid+userid2를 명령으로 해석
num=$((userid + userid2))계산됨 → 155$(( ))가 산술 확장 (괄호 두 겹, 앞에 $ 하나)
# [호스트 리눅스 · blue2 · 프롬프트 $ · /home/blue2]
vi test2.sh                    # 계산 실습 — 아래 내용으로 수정
# [호스트 리눅스 · vi 입력 모드 · blue2 · test2.sh 파일 안]
#!/bin/bash
userid=55
userid2=100
echo "$userid + $userid2"      # 55 + 100 — 계산 안 됨
num=$userid+$userid2
echo $num                      # 55+100 — 문자로 출력
num=$((userid + userid2))      # 괄호 두 겹 = 산술 계산
echo $num                      # 155
echo $((55 * 100))             # 5500 — 곱하기도 정상
# [호스트 리눅스 · blue2 · 프롬프트 $]
./test2.sh                     # 오류가 난 줄 번호까지 함께 출력됨

산술 형식$((변수 + 변수)) — 괄호 두 겹, 앞에 $ 하나괄호 안 변수에는 $를 붙이지 않아도 되고, 붙여도($(($userid + $userid2))) 동작함 (GNU Bash 매뉴얼 "Shell Arithmetic")

항목내용주의·이유

for in — 값 목록 반복 (test9.sh)

# [호스트 리눅스 · blue2 · 프롬프트 $ · /home/blue2]
vi test9.sh                  # for in 첫 실습 파일
# [호스트 리눅스 · vi 입력 모드 · blue2 · test9.sh 파일 안]
#!/bin/bash
for a in {1..5}; do          # a에 1~5를 하나씩 넣어 반복 ({1..5} = bash 중괄호 확장)
  echo "$a"                  # 반복마다 현재 값 출력
done                         # 반복문 종료 — 빼면 문법 오류
# [호스트 리눅스 · blue2 · 프롬프트 $]
chmod 700 test9.sh           # 실행 권한 x 부여 (1장 참고)
./test9.sh                   # 실행 → 1 2 3 4 5 (한 줄씩)
항목내용주의·이유
형식for 변수 in 값목록; do 명령; done값목록의 값을 변수에 하나씩 넣으며 do와 done 사이를 반복
실행 결과1 2 3 4 5 (한 줄씩)중괄호 확장이 1부터 5까지의 문자열을 만들어 냄
역순{5..1} → 5 4 3 2 1시작이 끝보다 크면 자동으로 역순
for문의 두 형식in 형 / 산술 (( )) 형for in도 for문이고, 이름만 구분해서 부름
반복문은 do로 열고 done으로 닫음 — done이 빠지면 실행 전에 문법 오류. {5..1}처럼 시작이 크면 역순으로 자동 전개

산술형 for — 시작·범위·증감

# [호스트 리눅스 · vi 입력 모드 · blue2 · test9.sh 파일 안 · 아래쪽]
for ((b=0; b<10; b++)); do   # 시작값 b=0 ; 범위값 b<10 ; 증감 b++ (b--는 1씩 감소)
  echo "$b"                  # 0부터 9까지 출력
done                         # 반복문 종료
구성내용주의·이유
실행 결과0 1 2 … 9 (10 미만)범위가 b<10이라 10은 찍히지 않음
(( ))산술연산 방식 — <·<=·>·>=·==·!= 기호를 씀수학식과 같은 기호라 읽기 쉬움
쓰지 않는 연산자-eq·-lt 같은 연산자는 [ ]·[[ ]] 안에서 쓰는 것(( )) 안에 넣으면 문법 오류
산술형 for 안에는 산술 기호만 — -eq·-lt는 [ ]·[[ ]]용이라 (( )) 안에서는 문법 오류

감소 반복과 실수 사례

# [호스트 리눅스 · vi 입력 모드 · blue2 · test9.sh 파일 안 · 아래쪽]
for ((c=9; c>0; c--)); do    # 1씩 감소, c>0이라 1에서 끝남 (0까지 찍으려면 c>=0)
  echo "$c"                  # 9부터 1까지 역순 출력
done                         # 반복문 종료
구분코드결과·이유
정상c>0 + c--9 8 7 … 1 (역순)
실수 1c<0 (기호 반대)처음부터 거짓이라 0회 실행 — 루프가 아예 안 돎
실수 2c-- 대신 c-2값이 바뀌지 않아 c>0이 계속 참 → 무한 루프(9 9 9 …)
2씩 감소c-=2변수에 다시 대입하는 형태라 조건이 언젠가 거짓이 됨
증감 자리에 c-2를 쓰면 값이 그대로라 무한 루프 — 변수 값을 바꾸는 c--·c-=2를 씀. 기호를 반대로 쓰면 0회 실행

2씩 증가·감소

# [호스트 리눅스 · vi 입력 모드 · blue2 · test9.sh 파일 안 · 아래쪽]
for ((d=1; d<=10; d+=2)); do  # d+=2 : 2씩 증가 (d-=2는 2씩 감소)

done                          # 반복문 종료
항목내용주의·이유
실행 결과1 3 5 7 9다음 값이 11이라 10은 찍히지 않음 — 범위가 <=10이어도 조건에 맞는 값만 나옴
증감 표기d+=2 / d-=21씩이 아닌 간격으로 늘리고 줄일 때

for 실행 순서 (a=1 · a<9 · a++)

순서하는 일결과
1시작값 a=1을 처음 한 번만 실행while 등 다른 반복문도 시작값은 한 번만
2첫 바퀴는 증가 없이 바로 본문(echo) 실행1 출력
3본문이 끝난 뒤 a++a=2 — 이전 값은 버려지고 변수는 계속 변함
4조건 확인 → 참이면 본문 → 증가 → 반복2, 3, … 8 출력
5a가 9가 되면 조건 불일치 → 전체 정지출력은 8까지
항목내용주의·이유
시작값 변경a=5처럼 시작값만 수정출력이 5부터로 바뀜 — 범위·증감은 그대로
시작값은 처음 한 번만, 증가는 본문이 끝난 뒤 — 첫 출력은 시작값 그대로. 조건 검사는 증가한 다음 값으로 함

while — 조건이 참인 동안 (test10.sh)

# [호스트 리눅스 · blue2 · 프롬프트 $ · /home/blue2]
vi test10.sh               # while 실습 파일
# [호스트 리눅스 · vi 입력 모드 · blue2 · test10.sh 파일 안]
#!/bin/bash
no=1                       # 시작값은 while 위에 먼저 선언
while (( no <= 5 )); do    # 조건 : 5 이하인 동안 반복
  echo "$no"               # 현재 값 출력
  ((no++))                 # 증가는 본문 안에 씀 (찍고 나서 1 증가)
done                       # 반복문 종료
# [호스트 리눅스 · blue2 · 프롬프트 $]
chmod 700 test10.sh        # 실행 권한 부여
./test10.sh                # 실행 → 1 2 3 4 5
항목내용주의·이유
실행 결과1 2 3 4 55를 찍고 6이 되면 조건이 거짓이라 정지
증가식 위치for는 증가식을 괄호 안에, while은 본문 안에 씀반복문마다 증가식 위치가 다름 — while에서 증가를 빼면 무한 루프
공백while 뒤는 한 칸 띄워 씀(( ))는 붙여 써도 동작하고, 공백이 꼭 필요한 건 [ ] 대괄호

실행 순서 (b=1 · b<3)

순서흐름결과
1시작값 b=1조건 판단 준비
2조건 참 → 1 출력 → 증가 b++ → b=2 → 맨 위로1 출력
3조건 참 → 2 출력 → 증가 → b=32 출력
4조건 불일치(b<3 거짓) → 정지출력 1, 2
while은 시작값을 위에 두고 증가를 본문 안에 — 증가를 빼거나 조건을 그대로 두면 무한 루프. 조건 판단은 증가한 뒤의 값으로 함

while 연습 — 12부터 5까지 역순

항목내용주의·이유
문제while문으로 12부터 5까지 역순 출력되는 셸 문법 작성조건·증감 방향을 함께 뒤집는 유형 — 출제 가능성이 높은 형태
푸는 방식문제를 # 주석으로 먼저 적고 그 아래에 코드 작성무엇을 만들지 코드 안에 남겨 두면 조건을 다시 볼 때 기준이 됨
예시 성격아래 코드는 강의 화면에 없던 표준 예시같은 결과를 내는 한 가지 방식 — 시작값·조건·증감만 맞추면 됨
# [호스트 리눅스 · vi 입력 모드 · blue2 · test10.sh 파일 안 · 연습]
# 문제 : while문으로 12부터 5까지 역순 출력
n=12                       # 시작값 — 큰 값에서 출발
while (( n >= 5 )); do     # 5 이상인 동안 (역순이라 >=)
  echo "$n"                # 현재 값 출력
  ((n--))                  # 1씩 감소
done                       # 반복문 종료
확인내용주의·이유
실행 결과12 11 10 9 8 7 6 55를 찍고 4가 되면 >=5가 거짓이라 정지
정방향은 <=·++, 역순은 >=·-- — 부호를 하나만 바꾸면 0회 실행이거나 무한 루프

until — 종료 조건까지 (test11.sh)

# [호스트 리눅스 · blue2 · 프롬프트 $ · /home/blue2]
vi test11.sh               # until 실습 파일
# [호스트 리눅스 · vi 입력 모드 · blue2 · test11.sh 파일 안]
#!/bin/bash
no=1                       # 시작값
until (( no >= 3 )); do    # 종료 조건 : no가 3 이상이 되면 정지
  echo "$no"               # 종료 조건 전까지 출력
  ((no++))                 # 증가는 while과 같이 본문 안
done                       # 반복문 종료
# [호스트 리눅스 · blue2 · 프롬프트 $]
chmod 700 test11.sh        # 실행 권한 부여
./test11.sh                # 실행 → 1 2
항목내용주의·이유
실행 결과1 2no가 3이 되는 순간 정지 — 3은 찍히지 않음
while과 차이while은 조건이 맞는 동안 반복, until은 종료 조건을 적고 맞으면 정지그래서 같은 3을 두고 부등호 방향이 달라 보임
핵심종료 조건(end point) 설정반대로 쓰면 무한 루프 또는 작동 불능 — for·while처럼 생각하면 안 됨
사용 빈도until은 많이 안 쓰임for·while을 알면 그걸 쓰면 됨
until은 "종료 조건" — 조건이 참이 되면 멈춤. while과 같은 감각으로 부등호를 쓰면 첫 판정부터 어긋나 0회 실행 또는 무한 루프

배열 — 선언·출력·개수 (test12.sh)

항목내용주의·이유
왜 배열서버에서 다룰 데몬(서비스)이 많아서 배열로 만들어 순차적으로 띄움배열은 반복문과 가장 같이 쓰임
# [호스트 리눅스 · vi 입력 모드 · blue2 · test12.sh 파일 안]
f=("hong" "kim" "park")    # 배열 선언 (원소는 공백으로 구분, 쌍따옴표는 생략 가능)
echo ${f[1]}               # 1번 값 → kim
echo ${f[@]}               # 등록된 배열 전체 → hong kim park
항목내용주의·이유
번호(index)무조건 0부터 — hong 0 / kim 1 / park 2번호를 노드 번호라고 부름
크기배열 크기 제한 없음데몬·서버 목록을 그대로 담음
변수명 재사용같은 변수명 f를 다시 쓰면 문제가 생김이전 선언을 #로 주석 처리한 뒤 새로 선언
실수f=("hong","kim","park")처럼 쉼표를 쓰면 원소 1개로 들어감${f[1]}이 빈 값 — 쉼표를 지우고 공백으로 구분
# [호스트 리눅스 · vi 입력 모드 · blue2 · test12.sh 파일 안 · 아래쪽]
d=("httpd" "nginx" "vsftpd")  # 데몬 이름 배열
echo ${#d[@]}                 # 전체 개수 → 3 (length와 비슷)
ea=${#d[@]}                   # 개수를 변수에 담음 (선택)
항목내용주의·이유
개수 표기${#배열[@]} — #이 개수, [@]가 전체개수를 읽어 두면 반복 범위를 자동으로 맞출 수 있음
마지막 번호개수 − 1 (개수 3이면 0, 1, 2)범위에 <= 금지
<=를 쓰면없는 3번을 읽게 되는데 bash는 에러 없이 빈 값을 줌조용히 오류가 남 — 실행은 끝나고 결과만 비어 있음
배열 번호는 0부터, 마지막 번호 = 개수 − 1 — 범위에 <=를 쓰면 없는 번호를 읽고 bash는 에러 없이 빈 값을 줌. 조용한 오류라 눈으로 확인해야 발견됨

같은 출력을 while · for in으로 (연습)

항목내용주의·이유
문제위 for 코드를 주석 처리하고 d·ea는 그대로 둔 채 while로 httpd nginx vsftpd 한 줄씩 출력같은 결과를 다른 반복문으로 만드는 연습 — 증가 위치만 다름
# [호스트 리눅스 · vi 입력 모드 · blue2 · test12.sh 파일 안 · while 연습]
b=0                      # 시작값 0
while (( b<ea )); do     # ea보다 작은 동안 반복
  echo ${d[b]}           # b번째 값 출력
  ((b++))                # 증가는 본문 안
done                     # 반복문 종료

# [호스트 리눅스 · vi 입력 모드 · blue2 · test12.sh 파일 안 · for in 연습]
for c in "${d[@]}"; do   # c가 배열 값을 하나씩 가져옴 (번호·개수 변수 불필요)
  echo "$c"              # 가져온 값 출력
done                     # 반복문 종료
방식특징주의·이유
for in값을 하나씩 꺼내므로 번호·개수 변수가 필요 없음세 줄이 한 번에 끝남
속도배열에서는 for in이 가장 빠름20만 개 배열 시연 측정: for in 약 0.7초 < 인덱스 for 약 1.2초 < while 약 1.4~1.5초 (환경에 따라 달라지는 값)
for·while의 위험범위를 직접 정해야 함100개를 50번만 돌리면 50개 손실 — 시작값·범위 실수가 데이터 누락으로 이어짐
배열 순회는 for in이 가장 빠르고 범위 실수도 없음 — 인덱스 for·while은 시작값 0과 범위(개수 − 1)를 직접 맞춰야 함

이중 for — 구구단 1~3단 (test13.sh)

# [호스트 리눅스 · blue2 · 프롬프트 $ · /home/blue2]
vi test13.sh                      # 이중 반복문 실습 파일
# [호스트 리눅스 · vi 입력 모드 · blue2 · test13.sh 파일 안]
#!/bin/bash
for ((a=1; a<4; a++)); do         # 바깥 : a = 1, 2, 3 (단)
  for ((b=1; b<10; b++)); do      # 안쪽 : b = 1~9 (곱하는 수)
    echo "$a x $b = $((a*b))"     # x, = 는 출력용 글자 / $((a*b))가 실제 계산
  done                            # 안쪽 for 종료
done                              # 바깥 for 종료
# [호스트 리눅스 · blue2 · 프롬프트 $]
chmod 700 test13.sh               # 실행 권한 부여
./test13.sh                       # 실행 → 1 x 1 = 1 … 3 x 9 = 27 (27줄)
항목내용주의·이유
실행 결과1 x 1 = 1 … 3 x 9 = 27바깥 3바퀴 × 안쪽 9바퀴 = 27줄
이중 반복문반복문 안에 반복문 ("더블 for")바깥·안쪽 do … done 짝을 맞춰서 봄
$((a*b))계산 결과를 문자열 안에 넣음$를 빼면 ((a*b)) 글자 그대로 출력됨

실행 순서

순서흐름결과
1a=1 → 안쪽 for가 b=1~9 전부 돎이 동안 a는 그대로 1
2b=10이 되면 안쪽 정지1단 9줄 완료
3바깥 a=2 → 안쪽 b가 다시 1부터 시작2단 9줄
4바깥이 한 바퀴 돌 때마다 안쪽은 처음부터 9바퀴같은 계산의 반복
5a=4가 되면 전체 종료27줄 출력 후 정지
바깥이 한 바퀴 돌 때 안쪽은 처음부터 전부 — for의 안쪽 변수는 괄호 안에서 매번 초기화되므로 단마다 1부터 다시 시작

이중 while과 초기화 버그

# [호스트 리눅스 · vi 입력 모드 · blue2 · test13.sh 파일 안 · 아래쪽]
c=1                                     # 바깥 시작값
while (( c<3 )); do                     # 바깥 2바퀴
  d=1                                   # 안쪽 시작값은 바깥 while 안, 안쪽 while 바로 위
  while (( d<6 )); do                   # 안쪽은 바깥 1바퀴당 5바퀴
    echo "$c x $d = $((c*d))"           # 현재 조합 출력
    ((d++))                             # 안쪽 증가 : 안쪽 done 앞
  done                                  # 안쪽 while 종료
  ((c++))                               # 바깥 증가 : 안쪽 done 뒤
done                                    # 바깥 while 종료
항목내용주의·이유
실행 결과1 x 1 ~ 1 x 5, 2 x 1 ~ 2 x 5바깥 2바퀴 × 안쪽 5바퀴
버그d=1을 바깥 while 위(c=1과 같이)에 두면 1 x 1~5만 나오고 2단이 안 나옴안쪽이 끝나면 d=6인데 d=1 줄이 반복문 밖이라 초기화가 안 됨
원인while은 시작값이 괄호 밖에 따로 있음for는 괄호 안이라 매번 초기화 — while에서 위치 실수가 생김
들여쓰기안 해도 됨가독성용 — 실행 결과는 같음
while 중첩은 안쪽 시작값을 바깥 while 안에 — 밖에 두면 두 번째 바퀴가 안쪽 조건(d<6)에서 바로 끝나 한 단만 출력

2차 배열 — 이중 반복문을 배우는 이유

항목내용주의·이유
1차 배열d=("httpd" "nginx" "vsftpd") 같은 목록반복문 하나로 돌림
2차 배열행렬 형태로 값이 두 축에 걸쳐 있음반복문도 2차, 3차가 필요 → 이중 반복문

뒤 숫자2차 노드번호 = 항목이름·IP·상태 같은 칸

반복문 + 조건문 — 짝수만 (test14.sh)

# [호스트 리눅스 · blue2 · 프롬프트 $ · /home/blue2]

#!/bin/bash
for ((a=1; a<=50; a++)); do
  if (( a % 2 == 0 )); then  # % = 나머지. 2로 나눈 나머지가 0이면 짝수 (1이면 홀수)

결합반복문과 if를 결합해 필요한 것만 처리조건문 문법은 2장의 then … fi 그대로

break — 반복문 강제 종료

# [호스트 리눅스 · vi 입력 모드 · blue2 · test14.sh 파일 안 · 아래쪽]
for ((b=1; b<=1000; b++)); do   # 1000까지 돌게 해 놓음
  if (( b > 30 )); then         # 30 초과일 때
    break                       # 반복문 강제 종료 (아래 코드는 실행 안 하고 바로 반복문 밖으로)
  fi                            # if 종료
  echo "$b"                     # break에 걸리지 않은 값만 출력
done                            # 반복문 종료
항목내용주의·이유

break는 조건이 맞는 순간 반복문 밖으로 — echo가 if 안이면 break가 걸린 값만, if 밖이면 걸리기 전 값까지 출력. 조건 안·밖 위치가 결과를 바꿈

함수 선언과 호출 — 선언이 먼저 (fn1.sh)

항목내용주의·이유
함수명령 묶음에 이름을 붙여 두고, 이름을 부르면(호출) 실행되게 하는 것파일명 fn1.sh의 fn은 function의 약자
선언과 실행선언만으로는 실행되지 않고 호출해야 작동선언은 붙여 두기, 실제 실행은 호출 줄에서
선언 형식 2가지function 이름 { ... } / 이름() { ... }어느 쪽을 써도 됨 — 같은 셸 함수 정의 문법이고 function 예약어만 선택 사항. 셸에는 메소드·클래스 개념 없음
중괄호 { }이번에 처음 사용if·for에서는 쓰지 않았음 — 함수 본문 묶음
같은 이름 두 개맨 마지막에 선언된 함수만 작동이름 중복 회피 — abc·bbb로 나눠 각각 호출

}
abc()  {                        # 예약어 없이 괄호만 쓰는 선언 형식 (같은 함수 정의)
  echo "()fn"                   # 이름이 abc로 같아 위 선언을 덮어씀
}
abc                             # 호출 = 함수 이름을 그대로 입력

함수에 인자 전달 (fn2.sh)

항목내용주의·이유
선언 괄호 ()비워 둠 — 다른 언어처럼 매개변수를 괄호에 쓰지 않음셸이 매개변수를 상관하지 않는 것이 아니라, 괄호가 빈 문법인 것. 인자는 위치 매개변수로 받음
값 전달호출할 때 함수 이름 뒤에 한 칸씩 띄워 인자값으로 전달abc "hong" "master" — 따옴표로 감싸면 공백이 있어도 한 값
함수 안에서 받기$1(첫 번째 값), $2(두 번째 값)번호는 항상 1부터 — 함수마다 새로 1부터 시작
용어매개변수(parameter) = 함수 정의 쪽 이름, 인자(argument) = 호출할 때 넘기는 값서로 다른 용어 — 셸 문서는 $1·$2를 위치 매개변수(positional parameters)라 부름
변수로 받기local nm=$1처럼 변수에 담아 씀보기 좋게 하는 방법일 뿐 강제 아님 — $1을 바로 출력해도 됨

  echo "username : $nm, role : $role"
}

지역 변수·전역 변수 (fn3.sh · fn4.sh)

구분선언사용 범위·주의
전역 변수함수 밖에서 id="hong", 또는 함수 안에서 local 없이 대입어디서든(다른 함수에서도) 사용 가능
지역 변수함수 안에서 local id="kim"scope = 사용 범위. 주로 함수 안에서 사용. bash의 local은 그 함수와 그 함수가 호출하는 함수·명령에서도 보임(동적 스코프)
변수 선언 2가지일반 선언 test1=aaa / local test1=aaa함수가 나오면서 차이가 생김 — 함수 밖에서는 local을 쓰지 않음
이름 짓기변수 이름을 서로 다르게같은 이름이 겹치면 지역·전역 중 무엇이 보이는지 헷갈림

#!/bin/bash
id="hong"                       # 전역 변수
fn_test() {
  local id="kim"                # 전역과 같은 이름의 지역 변수
  echo "$id"                    # 지역 변수 값 출력
}
fn_test                         # 함수 호출
echo "$id"                      # 전역 변수 값 출력
# [호스트 리눅스 · blue2 · 프롬프트 $]
./fn3.sh                        # kim / hong

#!/bin/bash
read -p "number1 : " no1       # 첫 번째 수 입력
read -p "number2 : " no2       # 두 번째 수 입력
sums() {
  local total=$(( $1 + $2 ))   # 산술 계산은 $(( 식 )) — 인자 두 개의 합
  echo $total                  # 결과 출력
}
sums $no1 $no2                 # 인자값 2개 전달

종합 — 데몬 시작·중지 함수 (fn6.sh)

# [호스트 리눅스 · vi 입력 모드 · blue2 · fn6.sh 파일 안]
#!/bin/bash
read -p "daemon select (vsftpd, nginx) : " dm   # 데몬 이름 입력
read -p "start or stop (st, sp) : " act         # st=start, sp=stop
d_start() { systemctl start $1; }              # $1 = 데몬 이름
d_stop()  { systemctl stop  $1; }
if [[ $act == "st" ]]; then                     # st 이면 start
  d_start "$dm"
else                                            # else 뒤에는 조건식을 쓰지 않음
  d_stop "$dm"
fi

배열일반 변수는 값 하나만 유지(j=1 후 j=10이면 1이 사라짐), 배열은 변수 하나에 여러 값괄호 ( ) = 배열을 만들겠다는 선언. 데몬 이름은 오타가 나면 에러라 정확히 입력

#!/bin/bash
dm=("nginx" "postgresql" "vsftpd")   # 괄호 = 배열 선언
process() {
  for z in "${dm[@]}"; do            # 배열의 모든 원소를 z에 하나씩 넣으며 반복
    systemctl $1 $z                  # $1 = start/stop, $z = 현재 데몬
  done                               # for 종료
}
read -p "데몬을 가동(st) 및 중지(sp) : " in   # 안내 문구는 문제 문서의 한글을 복사
if [[ $in == "st" ]]; then
  process "start"                    # 인자 start 전달
elif [[ $in == "sp" ]]; then
  process "stop"                     # 인자 stop 전달
else
  echo "해당 정보가 올바르지 않습니다"
fi

cp -r과 cp -a — 백업에 -a를 쓰는 이유

  • 차이
    cp -r은 소유자·그룹·권한·수정 시간이 명령을 실행한 사용자 기준으로 바뀌고 cp -a는 원본 그대로(원본을 750으로 바꿔 둔 상태면 복사본도 750, 날짜도 원본 그대로) — 비교 표·실습 결과·ls -l 검수: linux.html 6장
  • 이 장의 몫
    백업 스크립트에서 -a를 골라 쓰는 판단과, 복사 뒤 소유자·날짜를 원본과 맞춰 보는 검수 순서
# [호스트 리눅스 · root · 프롬프트 # · /home/blue2]
cp -a /home/aidata/html /home/blue2/back   # 속성 유지 복사 — 소유자·그룹·권한·수정 시간까지 그대로
ls -l back                                 # 안 파일의 소유자·날짜·권한이 원본과 같은지 확인
rm -drf back/html                          # 실습 되돌리기 — 다음 실습을 위해 복사본 삭제
백업·복구는 cp -a — cp -r은 소유자·그룹·권한·수정 시간이 복사한 사람 기준으로 바뀌어, 되돌린 뒤 원래 사용자가 파일을 고치지 못함. 날짜가 바뀌면 언제 고친 파일인지도 따질 수 없음

today=$(date +%Y%m%d)                     # 오늘 날짜 — 하이픈 없이 연월일

경로 실수 1 — 슬래시가 두 번(//) 붙는 경우

b_dir을 .../back/처럼 끝에 /를 붙여 두고 "$b_dir/..."처럼 또 붙이면 //가 됨. 이때 "디렉토리를 찾을 수 없음" 에러가 나지만, POSIX 경로 규칙상 연속 슬래시는 하나와 같게 취급되므로 // 자체가 원인은 아님 — 원인은 경로 값 자체의 오류.

슬래시를 넣은 채 뒤에 또 붙이기같은 실수 반복경로를 변수로 만들 때 끝 슬래시를 두지 않는 습관

항목내용주의·이유

명령 3가지

# [호스트 리눅스 · root · 프롬프트 #]
